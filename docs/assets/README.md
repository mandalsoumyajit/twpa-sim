# Project logo

[logo.png](logo.png) is the transparent PNG used in the project README. Its growing
coupled-wave form and repeated circuit motif represent amplification and
propagation; it is a visual symbol, not a literal circuit schematic.
Royal blue, teal and amber remain visible on light and dark backgrounds.
Use the native aspect ratio and provide a descriptive alt label.

The logo is included under the repository's [MIT License](../../LICENSE).
It was created with the **built-in image generation tool**, then refined
with one color edit on 2026-10-27. No external logo or reference artwork was supplied.

## Generation prompt

> Use case: logo-brand. Create a polished original logo SYMBOL ONLY for TWPA Sim, an open-source scientific Python toolkit for traveling-wave and resonant parametric amplifiers. A refined flat vector-like mark: a smooth wave grows from a small amplitude on the left to a large amplitude on the right, integrated elegantly with a short repeating superconducting transmission-line/circuit motif. The symbol should suggest propagation, parametric amplification and coupled waves, with very few deliberate geometric strokes. Use deep indigo, saturated teal/cyan and a restrained amber accent; strong contrast on both white and dark charcoal. Modern scientific software identity, precise geometry, generous negative space, memorable silhouette, clean solid colors, excellent legibility at 64px. Centered square composition, occupies roughly 75 percent of canvas. Genuine transparent background. No text, letters, equations, gradients, glow, shadows, photorealism, 3D, enclosing badge, mockup or watermark. Deliver one finished logo, not a sheet of alternatives.

## Final refinement prompt

> Use case: logo-brand, precise-object-edit. Edit this logo with ONE targeted change: replace every deep indigo/navy stroke and fill with a brighter medium royal blue (#4969E8), so the repeated circuit motif and lower wave stay clearly visible on dark charcoal as well as white. Preserve the exact geometry, composition, teal and amber elements, empty space, and all other design details. Keep a genuinely transparent background. No text, labels, border, shadow, mockup, or new elements.
